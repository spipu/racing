# Oswald (vendored)

Condensed display typeface of the menus, by Vernon Adams and The Oswald Project
Authors, from [googlefonts/OswaldFont](https://github.com/googlefonts/OswaldFont).

- File: `oswald.woff2` = `fonts/webfonts/Oswald[wght].woff2` of the repository
  (variable font, weights 200 to 700), unmodified — renamed only, the brackets
  of the original name being awkward in URLs.
